# 🏥 Patient Interface Module

The **Patient Interface** is a lightweight, responsive, and accessible dashboard designed specifically for elderly patients as part of the **SIH2026** cognitive wellbeing application. 

It features an intuitive user flow, large readable typography, and soft high-contrast visuals to ensure ease of navigation.
